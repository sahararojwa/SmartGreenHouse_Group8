Sistem monitoring dan otomasi greenhouse berbasis ESP32 untuk budidaya tanaman seledri. Membaca suhu, kelembaban udara, dan kelembaban tanah secara real-time, lalu mengontrol pompa air dan kipas angin secara otomatis. Data dikirim ke broker MQTT (HiveMQ) dan ditampilkan pada LCD 16x2.
Hardware: ESP32, DHT22, Soil Moisture Sensor, Relay 2 Channel, LCD 16x2 I2C
Library: DHTesp, LiquidCrystal_I2C, PubSubClient, WiFi.h
